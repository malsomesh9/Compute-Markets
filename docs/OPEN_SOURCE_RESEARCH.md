## Specific findings

Nosana actual program directory is programs/nosana-jobs, not programs/jobs in the brief. Its Market/Job/Run separation informs PDA relationships. The indexer README and signature-backfiller implementation describe an independent poll watermark; live arrivals cannot advance past an outage. Akash bidengine/order.go separates order subscription, capacity reservations, price calculation and lease lifecycle. Prime protocol README separates smart contracts, discovery, orchestrator, validators and workers, but the inspected protocol is archived. Bacalhau README supports the execution/storage adapter split.

Nosana node, kit, CLI, indexer and deployment-manager snapshots did not expose an identified root license; treat them as REVIEW and do not copy. Ray/KubeRay, gVisor, Firecracker, libp2p and distributed training remain future architecture references rather than implemented runtime integrations.

Version decision: npm reported @solana/kit 8.2.0, @coral-xyz/anchor 0.32.1 and Next 16.3.4. Anchor repository latest release is v1.2.0. The Rust/TypeScript boundary is deliberately pinned to matched 0.32.1 for installed CLI compatibility; this is not a claim that 0.32.1 is the newest Rust release. Migration to 1.2 and removal of legacy web3 transitive dependencies are release work.
