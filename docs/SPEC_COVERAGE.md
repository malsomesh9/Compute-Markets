# Specification coverage

The original brief combines an MVP, later V2/V3 research goals, public deployment, real GPU infrastructure and an independent audit. Those are tracked separately so a working local exchange is not reported as a production release.

| Scope                  | Current state                                                      | Evidence                                                                                                                                         | Remaining gate                                                                                |
| ---------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| Development MVP        | 18 of 19 acceptance areas exercised                                | Solana management and lifecycle tests, InsForge security tests, real CPU Docker flow, SDK/UI/build checks                                        | Real NVIDIA execution                                                                         |
| Solana protocol        | Implemented on devnet                                              | Deployed program, official devnet USDC config, escrow, bids, receipts, disputes, settlement, stake and agent policies                            | Independent audit, authority multisig and decentralized governance                            |
| InsForge control plane | Implemented                                                        | Migrations, RLS, private evidence, live/reconcile/history indexer, wallet proof, signed transaction integration and bounded inventory pagination | Multi-cluster isolation and production load test                                              |
| Provider runtime       | CPU and gVisor paths complete; GPU path implemented but unexecuted | Real OCI CPU evidence, full `runsc` flow, plus mock GPU-shaped fixture                                                                           | Authenticated NVIDIA host and malicious-container qualification                               |
| Verification           | VERIFY_0 through VERIFY_3 implemented; 4/5 adapters                | Receipt checks, signed hidden challenges, independent redundant quorum, attestation and Groth16 adapter tests                                    | Qualified TEE/proof deployments and permissionless verifier economics                          |
| Agent procurement      | Bounded policies implemented                                       | Merkle allowlist, token delegation, daily/per-job limits, owner UI, API/SDK/MCP and chain E2E                                                    | Broader predicates and long-lived service authentication                                      |

| Production release     | Blocked by external gates                                          | Local services, read-only public preview and repeatable devnet deployment preflight                                                              | GPU account, funded public Solana/USDC, monitoring qualification and independent audit        |

The development MVP covers every software acceptance area; its remaining hardware gate is a real NVIDIA run. V2 software paths are present. V3 has executable adapters, while confidential hardware, permissionless verifier economics, production proof circuits, and an independent audit remain external or substantial protocol gates. Percentages are intentionally omitted because these gates are binary and cannot be made complete by code claims.
